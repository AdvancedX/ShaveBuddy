# ShaveBuddy

ShaveBuddy 是一个本地优先的 Android / iOS 剃须记录与刀头寿命管理应用。

它帮助用户用尽可能少的操作完成四件事：

- 记录一次剃须；
- 回顾剃须日历；
- 了解当前刀片或刀头已经使用了多久、多少次；
- 获得下一次剃须和更换耗材的温和提醒。
