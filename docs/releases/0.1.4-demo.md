# ShaveBuddy 0.1.4-demo

发布日期：2026-10-17。适用于 Android 8.0 及以上的试用版。

## 这次更新

- 重新设计剃须满意度面板：用四条可拖动、可点选的滑杆替代重复表情；整体感受更突出，三个子项使用更细的轨道和更小的圆点。
- 增加简短引导、两端含义和当前评价标签，分别说明剃净度、顺滑度与皮肤感受。
- 每项默认「未填写」，可单独清空或全部跳过。最低档明确代表较差体验，与未填写分开；首次点选中间档也会正确记录。
- 保留三档评分与现有数据格式，已保存的剃须记录和满意度继续保留。

## 下载与升级

下载附件 **ShaveBuddy.apk**。0.1.3 用户也可进入「设置 → 检查更新」获取新版。直接覆盖安装即可，**不要先卸载**。

本版沿用既有 Debug 签名，不是商店安装包。记录保存在本机；卸载或清除应用数据会删除记录。
