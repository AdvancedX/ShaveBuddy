# ShaveBuddy 0.1.3-demo

发布日期：2026-10-16。Android 8.0 及以上可安装的试用预发布版。

## 这次更新

- 新增应用内更新：从今天、日历或装备页右上角进入设置，检查 GitHub 新版后自动下载，校验通过后交给 Android 系统确认安装。支持下载取消、失败重试和继续安装。
- 新增剃须满意度：记录成功后，可分别填写总体、剃净度、顺滑度和皮肤状况，选择「不满意 / 一般 / 满意」。每项均可跳过，跳过不影响已保存的剃须记录。
- 日历日期格显示当天最近一次已填写的总体评分，点选日期可查看每次剃须的四项评分。
- 改善日期与星期标题排版，窄屏和大字体下会整体换行。

## 下载与升级

下载附件 **ShaveBuddy.apk**。已安装 0.1.2 或更早试用版时，直接覆盖安装，**不要先卸载**。此版沿用旧包签名，数据库自动升级并保留原有装备、刀片周期和剃须记录；历史记录的满意度默认为未评分。

旧版尚无应用内更新，因此需要手动下载并安装本版一次，之后即可在「设置」中检查更新。应用内更新需要手机能访问 GitHub，安装仍需系统授权和确认。

这是沿用既有 Debug 签名的试用包。剃须记录与满意度只保存在本机；更新功能仅在主动检查或下载时联网，不上传记录。当前没有备份功能，卸载或清除应用数据会删除记录。
