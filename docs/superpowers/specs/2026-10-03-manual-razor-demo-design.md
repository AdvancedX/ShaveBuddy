# 手动剃须刀 Demo

用户已授权按文档开始开发，并将首个版本限定为基本功能与手动剃须刀；开发过程分批提交。

## 范围与技术决策

采用较新的开工清单中的 Android 原生方向：Kotlin、Compose Material 3、ViewModel/StateFlow、Room，单个 app module。最低 API 26，编译和目标 API 37。Demo 使用 `com.shavebuddy.demo`，仅用于本地测试，发布身份以后确定。iOS、通知、导入导出、多装备、评分和备注不在本次范围。此 Demo 不代表阶段 0 全部通过。

## 用户流程

首次打开填写装备名称、刀片安装日期、可选次数/天数目标与剃须间隔，保存后进入“今天”。提供三个入口：今天、日历、装备。今天一键记录当前日期，另可选择日期补记；同日允许多条记录。日历标记日期，点选后查看并确认删除。装备可编辑目标和间隔，并确认更换刀片；更换结束旧周期并保存历史，当前统计归零。

采用温暖浅色背景、石墨文字与蓝绿色主色，并提供跟随系统的深色主题。页面可滚动，按钮有文字标签，关键表单状态在旋转时保留。

## 数据与边界

Room 保存单件手动装备、耗材周期与剃须记录。每条记录包含周期 ID、发生时本地日期、UTC 时间和时区。更换后的历史不会重新关联。补记日期通过周期安装日与结束日匹配；同日更换时选择最新安装周期；不允许未来日期或早于第一周期的记录。周期结束日是上界（不含），同日更换的旧记录仍保留在旧周期。设置变更仅修改当前周期阈值。

使用次数由当前周期记录计数；天数为安装日期到今天自然日差；达到任一启用目标时温和建议更换。最近一次记录按本地日期和时间排序，下次日期为最近本地日期加间隔；没有记录则无预测。日期计算使用 java.time，不通过毫秒除法估算自然日。

UI 只调用 ViewModel；ViewModel 调用 Repository；Repository 用事务完成初始化、更换和增删记录。保存错误显示可重试提示，写入时禁用操作，数据库错误不清空数据。回到前台与日期变化后重新读取今天。

## 验证

纯 Kotlin 测试覆盖同日多次、次数/天数阈值、关闭目标、闰年/月末、夏令时、无记录、删除重算、周期匹配和非法输入。设备测试使用真实 Room 验证重开数据库、事务与历史关联，并验证首次设置到记录/更换的 Compose 流程。执行单元测试、assembleDebug 和 lintDebug；有模拟器时执行设备测试。真机、通知可靠性与发布构建保留为后续验收。
